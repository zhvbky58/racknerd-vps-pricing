续费那条要单独说。很多商家首年 $2.99，第二年涨到 $10.99，RackNerd 的 Specials 官方 FAQ 明确写的是 lifetime recurring，不取消就一直同价。这是它和低价商家最实质的区别之一。

代价是灵活性。取消必须在续费日前**至少 5 天**通过客户中心提交，取消后数据立即删除，得先备份。账单逾期 3 天可能收 **10% 滞纳金**，多数服务在到期 **7 天**后仍未付款会自动终止，数据不可恢复；独立服务器更紧，最早到期 3 天就可能被回收。

## 下单与开机

流程本身不长，容易出错的地方集中在这几步。

1. **选套餐**。Specials 页面点 Order Now 进购物车。
2. **确认 Location**。这一步必须手动看。默认机房不一定是你要的那个，一路点下一步很容易开到别处去。
3. **选系统**。新手用 Ubuntu 24.04 或 Debian 13。下单页标注 Debian 11/12 建议至少 2GB 内存，1GB 套餐别选 Debian。
4. **填真实信息**。姓名、地址、常用邮箱都要真实，账单、续费提醒和开通邮件都发到这个邮箱。
5. **付款**。结账页支持 PayPal、信用卡、Stripe 支付宝、银联卡、USDT/USDC 稳定币、Boleto 和电汇。没有微信支付，国内用户走支付宝最省事。
6. **收邮件**。开通后收到标题为 "KVM VPS Login Information" 的邮件，里面有 IP、root 密码、ctrl 面板地址和登录账号。官方说多数部署在 5 到 15 分钟内完成。

**面板这块要更正一个过时说法。** 现在所有 KVM、Windows、Ryzen VPS 用的都是 RackNerd 自研的 **ctrl** 面板，地址 ctrl.racknerd.com，用户名以 vmuser 开头，不是你注册客户中心用的邮箱。能做的事包括重启、重装系统、HTML5 VNC 控制台、网络防火墙、一键应用、查看流量。网上不少旧文章还写 SolusVM，那是 2021 年之前的界面，早换了。

开机后按顺序做四件事：改 root 密码、`apt update && apt upgrade -y`、换成密钥登录并关掉密码登录、开防火墙。ctrl 面板里的网络防火墙在流量到达系统之前就做过滤，VNC 不受它影响，配错了还能从控制台救回来。1GB 内存的机器再挂 1 到 2GB swap，跑编译和小服务会稳一些。备份自己做，服务条款写明 RackNerd 不对数据完整性负责。
